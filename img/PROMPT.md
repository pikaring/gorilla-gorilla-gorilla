# 札の絵を作るためのプロンプト

9枚を**1枚のグリッド画像**として一度に出させ、`tools/split_grid.py` で切り分ける。
1枚ずつ作るより画風が揃う——9枚並べたときに線の太さや濃さがばらつかないことが、
札として使ううえでいちばん効く。

ゴリラ（第5段）がちょうど**中央のコマ**に来るように並べてある。

---

## プロンプト（このまま渡す）

```
カードゲーム用の小さな挿絵を9つ、1枚の画像にまとめて描いてください。

【全体の形式】
- 正方形（1:1）の画像を1枚。できるだけ高い解像度で
- 中を 3列 × 3行 の9コマに等分する
- コマの区切りとして、細い黒の直線を縦2本・横2本だけ引く
- 画像のいちばん外側には枠線を引かない
- 各コマの背景は純白（#FFFFFF）。灰色がからないこと

【9コマに共通する絵の指定】
- 描線は黒1色（#14100C）のみ。グレーの階調は最小限にとどめ、色は一切使わない
- 木口木版画／スクラッチボード風の線画。輪郭を太く強く、内部の細部は最小限
- 博物館の標本図版のような、落ち着いた図鑑の絵
- 被写体はコマの約80%に収め、区切り線に触れないよう余白を残す
- 幅48ピクセルに縮小しても、何が描かれているか判別できること
- 文字・数字・記号・署名を入れない（⑧だけ例外。下記）
- 影、地面の線、背景の風景を入れない
- 9コマすべてで線の太さと画風を揃える。1コマだけ濃い／細いということがないように

【各コマの中身】左上から右へ、上の段から順に

1段目
① 樹上のサル
   細い枝に片手でぶら下がる小型の霊長類を真横から。長い尾と細い四肢。
   枝は画面を斜めに横切る一本だけにする。葉は描かない。
② 火のボノボ
   小さな焚き火の前にしゃがみ、炎に手をかざすボノボを真横から。
   炎は尖った3つの形に単純化する。薪は2本の棒で足りる。
③ 直立二足歩行
   直立して歩く初期人類（アウストラロピテクス）の全身を真横から。
   前に踏み出した足と、振った腕が分かる歩行の姿勢。体毛は輪郭の乱れとして最小限に。

2段目
④ 石器
   人の手に握られた涙形の握斧（ハンドアックス）。打ち欠いた面の稜線を数本の線で表す。
   手は輪郭だけにして、石器を主役にする。
⑤ ゴリラ
   正面を向いたシルバーバックのゴリラの胸像。太い眉弓、広く平らな鼻、厚く盛り上がった肩。
   9つのうち最も輪郭を強く、最も目を引くように描く。
   ちょうど中央のコマなので、ここが絵全体の中心に見えるようにしたい。
⑥ 言語
   向かい合う2つの人の横顔。その間に、声を表す渦巻きを1つだけ浮かべる。
   左右対称にせず、片方をやや大きくして奥行きを出す。

3段目
⑦ 農耕
   地面から立つ麦の穂を5本ほどと、その手前に斜めに置かれた鍬。
   実の粒は描き込まず、輪郭の膨らみで表す。
⑧ 文字と都市
   楔形文字が刻まれた四角い粘土板を正面から。背後に段状の塔（ジッグラト）の輪郭が小さく覗く。
   ※ここだけは文字を入れてよい。ただし実在の文字として読める必要はなく、
   　くさび形の刻みを並べた模様として扱ってよい。
⑨ 現生人類
   現代人の横顔の胸像。①の樹上のサルと同じ向き・同じ大きさで並ぶように描く。
   進歩の階段の始まりと終わりが呼応するようにしたい。
```

## 切り分け

```
pip install pillow numpy
python3 tools/split_grid.py grid.png
```

`img/1.png` 〜 `img/9.png` が書き出される。区切り線を自動で見つけてコマに割り、
外側とつながっている白を透過して、512×512の正方形に揃える。

9コマに割れないと言われたら、**区切り線がはっきり出ているか**と、
**画像のいちばん外側に枠線が入っていないか**を確かめる。外枠があると
それも区切り線として拾われてしまう。

1コマだけ描き直したときは `--only` で上書きできる。

```
python3 tools/split_grid.py grid2.png --only 5
```

スクリプトを使わず、手で9分割して `1.png`〜`9.png` と名前を付けても動く。
札は `mix-blend-mode: multiply` で敷いているので、**白背景のままでも地色に抜ける**——
透過は必須ではない。

---

## なぜ9枚で足りるのか

札は4大陸×9段の36枚あるが、**大陸は札の上端の色帯で表している**ので、絵は段ごとの9枚で足りる。
同じ絵を4色のカードで使い回すため、**絵に色を持たせてはいけない**。これがこのプロンプトで
いちばん外せない制約。

レインボーゴリラはゴリラなので `5.png` を共用する。10枚目は要らない。

## 仕上がりの確認

- 9枚を並べて**画風が揃っているか**。1枚だけ濃い／細いと札にしたとき浮く
- **48ピクセル幅に縮めて**まだ判別できるか。だめなら細部を削る
- 背景が**純白か**。灰色がかっていると multiply で汚れて見える
- ⑤が他より弱くないか。ここが弱いとゲームの要が沈む
