# 札の絵を作るためのプロンプト

9枚を**1枚のグリッド画像**として一度に出させ、`tools/split_grid.py` で切り分ける。
1枚ずつ作るより画風が揃う——9枚並べたときに線の太さや濃さがばらつかないことが、
札として使ううえでいちばん効く。

ゴリラ（第5段）がちょうど**中央のコマ**に来るように並べてある。

## 先に知っておくこと

**札の中で絵が出るのは幅40ピクセルほどしかない。** ここを外すと何を描いてもらっても使えない。

- **細い輪郭線だけの絵（ぬりえ風）は潰れる。** 縮めると線が平均化して灰色の塊になる。
  黒のベタ面で形を作らせること。実寸での黒の割合が20%を切ると判別できなくなる
- **文字・数字は必ず禁じる。** 指示の中で「①樹上のサル」のように番号と名前を書くと、
  画像生成AIはそれをコマの中に書き込んでしまう。下のプロンプトでは番号を使わず、
  位置（左上・上段中央…）で呼んでいるのはそのため

切り分けるときに実寸での黒の割合が表示されるので、それで判断できる。

## プロンプト（このまま渡す）

```
9つの小さな挿絵を、1枚の画像にまとめて描いてください。
カードゲームの札に使うもので、最終的に幅40ピクセルまで縮小して表示します。
そのため細部よりも、小さくしても崩れない「大きな黒い形」が要ります。

【いちばん大事なこと】
- 画像の中に文字・数字・記号を一切描かないでください。
  英語も日本語も、番号も、キャプションもラベルも要りません。
  下の「左上」「上段中央」といった位置の呼び名と、描く対象の名前は、
  あなたへの指示であって、絵に書き込むものではありません。
- 細い輪郭線だけの絵にしないでください。
  ぬりえ・コロリングブック・クリップアートのような均一な細線の絵は不可です。
- 黒のベタ塗りで形を作ってください。各コマの面積の30〜45%が黒で埋まるくらい。
  影やハッチングではなく、輪郭のはっきりした黒い面で。

【全体の形式】
- 正方形（1:1）の画像を1枚。できるだけ高い解像度で
- 中を 3列 × 3行 の9コマに等分する
- コマの区切りとして、細い黒の直線を縦2本・横2本だけ引く
- 画像のいちばん外側には枠線を引かない
- 各コマの背景は純白（#FFFFFF）

【画風】
- 黒1色（#14100C）のみ。灰色の階調は使わない
- リノリウム版画や切り絵のような、黒い面と白い抜きだけで作る絵
- 対象はコマの85%を占める大きさ。ひとつの対象だけを大きく描く
- 内側の描き込みは、白く抜く線3〜4本まで。それ以上は描かない
- 影、地面の線、背景の風景を描かない
- 9コマすべてで黒の濃さと形の作り方を揃える

【各コマに描くもの】

左上
  枝にぶら下がる小型のサル。体は黒く塗りつぶし、長い尾を大きな曲線で見せる。
  枝は太い1本だけ。顔の中身は描かず、シルエットのままにする。
上段中央
  焚き火の前にしゃがむボノボ。体は黒く塗りつぶす。
  炎は白く抜いた尖った3つの形にして、黒い体と対比させる。
上段右
  直立して歩く初期人類の全身。まるごと黒いシルエット。
  前に踏み出した足と、振った腕が、輪郭だけで分かるように。
中段左
  涙形の握斧（石器）を握った手。石器を大きく黒く塗りつぶし、
  打ち欠いた面は白く抜いた線3本で示す。手は黒い握りの形だけ。
中央
  正面を向いたゴリラの顔。9つのうち最も黒が多く、最も強い形にする。
  目と鼻と口は白く抜く。ここが絵全体の中心に見えるようにしたい。
中段右
  向かい合う2つの横顔。どちらも真っ黒なシルエットにする。
  あいだの白い余白に、白く抜いた渦巻きを1つだけ浮かべる。
下段左
  麦の穂を3本だけ、太く大きく。穂は黒く塗りつぶす。細い茎を増やさない。
下段中央
  段状の塔（ジッグラト）の黒いシルエット。手前に粘土板を1枚重ね、
  くさび形の刻みを4本ほど白く抜く。実在の文字として読めなくてよい。
下段右
  現代人の横顔。まるごと黒いシルエット。
  左上のサルと同じ向き・同じ大きさで並ぶように描く。

最後にもう一度。画像の中に文字と数字を入れないでください。
```

## 切り分け

```
pip install pillow numpy
python3 tools/split_grid.py grid.png
```

`img/1.png` 〜 `img/9.png` が書き出される。区切り線を自動で見つけてコマに割り、
外側とつながっている白を透過して、256×256の正方形に揃える。
札で絵が出るのは最大42pxなので、3倍の画面でもこれで足りる（512にすると重くなるだけ）。

書き出しながら**実寸（幅38px）での黒の割合**が出る。**20%を下回ったら使えない**と思ってよい。

```
1.png 樹上のサル  実寸での黒 21%
3.png 直立二足歩行  実寸での黒 18%  ← 薄い。--bold か描き直しを
```

薄いときは線を太らせて救える。

```
python3 tools/split_grid.py grid.png --bold 5
```

`--bold 5` あたりが効く。7まで上げると細かいコマが潰れる。
ただし**文字が写り込んでいる絵は太らせると余計に目立つ**ので、そのときは描き直すしかない。

9コマに割れないと言われたら、**区切り線がはっきり出ているか**と、
**画像のいちばん外側に枠線が入っていないか**を確かめる。外枠があると
それも区切り線として拾われてしまう。

1コマだけ描き直したときは `--only` で上書きできる。

```
python3 tools/split_grid.py grid2.png --only 5
```

スクリプトを使わず、手で9分割して `1.png`〜`9.png` と名前を付けても動く。
札は `mix-blend-mode: multiply` で敷いているので、**白背景のままでも地色に抜ける**——
透過は必須ではない。

## なぜ9枚で足りるのか

札は4大陸×9段の36枚あるが、**大陸は札の上端の色帯で表している**ので、絵は段ごとの9枚で足りる。
同じ絵を4色のカードで使い回すため、**絵に色を持たせてはいけない**。

レインボーゴリラはゴリラなので `5.png` を共用する。10枚目は要らない。

## 仕上がりの確認

- **文字と数字が写り込んでいないか。** いちばん起きやすい失敗
- **実寸での黒の割合が20%を超えているか。** 切り分けのときに表示される
- 9枚を並べて**画風が揃っているか**。1枚だけ濃い／細いと札にしたとき浮く
- 中央のゴリラが他より弱くないか。ここが弱いとゲームの要が沈む
