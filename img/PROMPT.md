# 札の絵を作るためのプロンプト

画像生成AI（Gemini など）に1枚ずつ渡す。**共通仕様**を前置きして、**各段の指定**を続ける。

---

## 共通仕様（毎回そのまま前置きする）

```
カードゲームのアイコンとして使う小さな挿絵を1枚描いてください。

【形式】
- 正方形（1:1）、1024×1024ピクセル
- 背景は純白（#FFFFFF）。灰色がからないこと
- 描線は黒1色（#14100C）のみ。グレーの階調は最小限にとどめ、色は一切使わない
- 被写体は画面の約80%に収め、上下左右に均等な余白を残す

【画風】
- 木口木版画／スクラッチボード風の線画
- 輪郭を太く強く、内部の細部は最小限
- 博物館の標本図版のような、落ち着いた図鑑の絵

【制約】
- 幅48ピクセルに縮小しても、何が描かれているか判別できること
- 文字・数字・記号・枠線・署名を入れない
- 影、地面の線、背景の風景を入れない
- 4種類の色のカードで同じ絵を使い回すので、絵そのものに色や色の含みを持たせない

【描くもの】
```

---

## 各段の指定（上の【描くもの】に続ける）

### 1.png — 樹上のサル
```
細い枝に片手でぶら下がる小型の霊長類を、真横から。長い尾と細い四肢。
枝は画面を斜めに横切る一本だけにする。葉は描かない。
```

### 2.png — 火のボノボ
```
小さな焚き火の前にしゃがみ、炎に手をかざすボノボを真横から。
炎は尖った3つの形に単純化する。薪は2本の棒で足りる。
```

### 3.png — 直立二足歩行
```
直立して歩く初期人類（アウストラロピテクス）の全身を真横から。
前に踏み出した足と、振った腕が分かる歩行の姿勢。体毛は輪郭の乱れとして最小限に。
```

### 4.png — 石器
```
人の手に握られた涙形の握斧（ハンドアックス）。
打ち欠いた面の稜線を数本の線で表す。手は輪郭だけにして、石器を主役にする。
```

### 5.png — ゴリラ（最重要）
```
正面を向いたシルバーバックのゴリラの胸像。
太い眉弓、広く平らな鼻、厚く盛り上がった肩。
このゲームの主役の札なので、9枚のうち最も輪郭を強く、最も目を引くように描く。
```

### 6.png — 言語
```
向かい合う2つの人の横顔。その間に、声を表す渦巻きを1つだけ浮かべる。
2つの顔は左右対称にせず、片方をやや大きくして奥行きを出す。
```

### 7.png — 農耕
```
地面から立つ数本の麦の穂と、その手前に斜めに置かれた鍬。
穂は5本ほど。実の粒は描き込まず、輪郭の膨らみで表す。
```

### 8.png — 文字と都市
```
楔形文字が刻まれた四角い粘土板を正面から。背後に段状の塔（ジッグラト）の輪郭が小さく覗く。
※ここだけは「文字を入れない」の例外。ただし実在の文字として読める必要はなく、
　くさび形の刻みを並べた模様として扱ってよい。
```

### 9.png — 現生人類
```
現代人の横顔の胸像。
1.png の樹上のサルと同じ向き・同じ大きさで並ぶように描く。
進歩の階段の始まりと終わりが呼応するようにしたい。
```

## 仕上がりの確認

- 9枚を並べて**画風が揃っているか**。1枚だけ濃い／細いと札にしたとき浮く
- **48ピクセル幅に縮めて**まだ判別できるか。だめなら細部を削る
- 背景が**純白か**。灰色がかっていると `mix-blend-mode: multiply` で汚れて見える
- 5.png が他より弱くないか。ここが弱いとゲームの要が沈む
