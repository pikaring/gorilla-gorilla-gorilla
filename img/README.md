# 札の絵

ここに `1.png` 〜 `9.png` を置くと、ゲームと紹介ページの札が自動で絵に切り替わる。
1枚も無い状態でも文字だけの札としてそのまま遊べる（`5.png` の有無だけを見て判定している）。

## なぜ9枚で足りるのか

札は4大陸×9段の36枚あるが、**大陸は札の上端の色帯で表している**ので、絵は段ごとの9枚で足りる。
同じ絵を4色のカードで使い回すため、**絵に色を持たせてはいけない**。

レインボーゴリラはゴリラなので `5.png` を共用する。10枚目は要らない。

## 表示のしくみ

絵は `mix-blend-mode: multiply` で敷いている。**白い背景は自動で消えて札の地色になる**ので、
背景を透過させていないPNGでもそのまま使える（透過PNGでも問題ない）。
ただし背景は純白であること。灰色がかっていると汚れて見える。

絵を入れると札の上の「アフリカ」などの大陸名は隠れ、代わりに色帯が太くなる。
数字と段の名前は残る。

## 差し替え手順

1. [`PROMPT.md`](PROMPT.md) のプロンプトで、9枚を **3x3のグリッド画像1枚** として出させる
2. 切り分ける

       pip install pillow numpy
       python3 tools/split_grid.py grid.png

3. ブラウザで開き直す

1枚ずつ作らずグリッドにまとめるのは、**9枚並べたときに画風が揃う**ため。
線の太さや濃さがばらつくと、札にしたとき1枚だけ浮く。

手で9分割して `1.png`〜`9.png` と名前を付けても構わない。

うまく出ないときは、まず `5.png` が読めているかを確認する。これが読めないと他の8枚も出ない。
