どんなゲーム

四つの大陸と、
九つの進歩の段。

手の内は9枚。3枚で一組をなし、三組を揃えれば上がりとなる。麻雀と異なり雀頭は要しない。三組ならば9枚で割り切れるためである。

01

系譜と伝播

組は二種に限られる。系譜は同じ大陸の連続する三段、 伝播は同じ段が異なる三つの大陸に揃った形である。

  • 系譜：アフリカ 3-4-5 のように段を登る
  • 伝播：7がアフリカ・ユーラシア・アメリカに揃う
  • レインボーゴリラは欠けた1枚を補う（1組に1枚まで）
02

第5段に座すゴリラ

系譜は一つの大陸につき7通り存在するが、そのうち 3-4-5 / 4-5-6 / 5-6-7 の3通りはゴリラを経ずして繋がらない。中盤の進歩を扱う者は、必然的に罰10点を抱えることになる。

  • 通常の札は、段の数字がそのまま失点となる
  • ゴリラとレインボーゴリラのみ罰10点
  • 5の伝播（3大陸ぶんのゴリラ）は抱え込みで30点
03

公開か、秘匿か

揃った組は公開できる。公開した組は精算で0点、伏せたままならば札の点がそのまま失点となる。ただし公開は、手の内を相手に明かすことにほかならない。

  • 公開の利点は、相手に先に上がられた場合の保険に尽きる
  • 残りの組数が知れれば、相手は危険な札を止める
  • 相手が迫れば公開し、なお遠ければ伏せて粘る
04

現生人類への到達

第9段の現生人類を組に用いて上がれば、1枚につき9点の加点となる。伏せたままならば9点の失点となる札であり、損得はちょうど反転する。

  • 系譜 7-8-9 で +9点
  • 9の伝播（3大陸分）で +27点
  • レインボーが9を代替した場合は数えない

あそびかた

一枚を引き、一枚を捨てる。

ポン・チーに相当する割り込みは存在しない。相手の手番中になし得ることは一切なく、考えるべきは、自らの番に何を引き何を捨てるか、のみである。

01

山札か、捨て札か

いずれから引いてもよい。ただし捨て札を拾った手番では山札は減らない。拾うほど局は延び、急ぐか粘るかの判断は山札の残り枚数に直結する。

02

「ゴリラ！」の宣言

2人対戦であるから、自らの手番に置かれた捨て札は、必ず相手が直前に捨てた札である。すなわちそれを拾って上がれば、実質的なロンとなる。山札から引いても拾っても、宣言は「ゴリラ！」である。

03

ゴリラ宣言による打ち切り

三組が揃う前であっても、2組＋出すゴリラ1枚＋残り2枚が10点未満ならば局を終わらせることができる。得点は相手の伏せ札との差のみ。取り分は小さいが、相手が手を仕上げる前に局を断つ。

04

精算

上がられた側は、伏せ札の合計点を相手に献上する。山札が尽きれば強制精算となり、伏せ札の少ない側がその差を得点する。先に100点に達した側の勝利とする。

つくり

HTML / CSS / JavaScript だけ。

フレームワークもビルドも用いない。app/index.html を開けば、そのまま動作する。題はジャレド・ダイアモンド『若い読者のための第三のチンパンジー』に拠り、リポジトリ名はニシゴリラの学名 Gorilla gorilla gorilla に由来する。ゴリラの名が三度並ぶ学名である。

組の 分解手の内を「組数の最大化、次いで失点の最小化」の順に全探索する。レインボーは1組1枚までの代替として候補に加える。
相手の 思考拾いの損得、公開の是非に関するリスクの見積もり、そして「あなたがどの札を拾ったか」から推し量った危険度に基づき、捨て札を選ぶ。
札の 絵画像生成AIに3×3のグリッドとして描かせ、tools/split_grid.py で切り分け、背景透過を施している。大陸は色帯で表すため、絵は9枚で足りる。
ルールの 仕様RULES.md に、札・手番・上がり・精算を数値と条件で記している。
保存何も保存せず、サーバーにも一切送信しない。

よくある質問

疑問に答える

お金は かかりますか？

かからない。無料であり、広告も課金もない。

インストールは 必要ですか？

不要である。ブラウザで開くだけで遊べる。

データは どこかに 送られますか？

送られない。得点も設定もその場限りで、保存すらしていない。

原作のカードゲームを 持っていないと 遊べませんか？

必要ない。本作は原作とはルールを異にする、別個のゲームである。

なぜ 第5段が ゴリラなのですか？

進歩の道の中央にゴリラを置けば、中盤の系譜は必ずゴリラを経由する。いかに段を登ろうともゴリラからは逃れられない、という原作の主題が、そのまま確率の構造として現れるためである。

ゴリラを 抱えたままだと 損ですか？

損である。伏せたまま終われば罰10点となる。ただしゴリラ宣言に用いて場に出せば、その1枚は失点に数えない。抱えれば重荷、出せば切り札、という札である。

2人で 対戦できますか？

現在はCPU対戦のみである。むずかしさは やさしい／ふつう／ゴリラ級 の3段階を用意している。
